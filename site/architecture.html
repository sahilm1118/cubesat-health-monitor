System architecture

From raw sensor readings to an onboard decision

Each stage below runs in this project's code on real data, except the last, which is the proposed onboard response.

Inside a 3U CubeSat · hover a module

Acquire

Attitude-control magnetometer (3 axes) and six sun-sensing photodiodes from OPS-SAT, plus battery voltage, current and temperature.

9 telemetry channels + EPS

Segment & extract

Each channel is cut into short windows. Every window is summarised by statistical features such as variance, kurtosis, skew, peak counts and gap patterns.

features / window

Detect

120 compact decision trees vote on each window. A classic limit check runs alongside, and the two are combined into a hybrid alarm.

Extra Trees + limits

Forecast

Battery state of health is estimated from the first 15 minutes of a discharge. Remaining useful life comes with a 90% uncertainty range.

GBR + RF + conformal

Respond

A fault-management state machine escalates from Monitor to Isolate to Safe mode, and recovers when telemetry is clean again. It is tested in simulation.

FDIR · simulated

Telemetry: ESA OPS-SAT via the OPSSAT-AD dataset (CC BY 4.0). Battery data: NASA Ames Prognostics Center of Excellence.
