Autonomous fault management

Closing the loop: detect, decide, recover

Detection alone doesn't protect a satellite. Here the model drives a fault-management (FDIR) state machine through a stretch of real OPS-SAT telemetry with an injected fault episode. You can compare three strategies side by side: the AI alone, classic limits alone, and the hybrid.

    Rules: any alarm → Monitor. Two alarms in a row → Isolate (stop using the sensor's data). Four in a row with p ≥ 0.9 → Safe mode. Three clean windows in a row → step down one level. The state machine is a proposed design, tested here in simulation.

    The trade-off in numbers

    Caught: the fault raised an alarm during the episode. Delay: windows from fault start to first alarm. False alarms: alarms per 100 genuinely nominal windows before the episode.

    Telemetry: ESA OPS-SAT via the OPSSAT-AD dataset (CC BY 4.0). Battery data: NASA Ames Prognostics Center of Excellence.
